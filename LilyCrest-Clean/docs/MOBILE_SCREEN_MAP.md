# LilyCrest Mobile Screen Map

Last reviewed: 2026-05-27

Runtime mobile API base:

- `https://mobile-api.lilycrest.space/api/m`

Do not use or change the web/admin API domain in mobile runtime:

- `https://api.lilycrest.space`

## Navigation Overview

Root stack is defined in `frontend/app/_layout.jsx`.

Visible tab bar routes are defined in `frontend/app/(tabs)/_layout.jsx`:

- `/(tabs)/services`
- `/(tabs)/announcements`
- `/(tabs)/home`
- `/(tabs)/billing`
- `/(tabs)/profile`

Hidden tab routes:

- `/(tabs)/dashboard`
- `/(tabs)/chatbot`

## Missing Or Incomplete Screens

- `/(tabs)/dashboard` is a hidden placeholder that says "Dashboard - Redirecting to Home..." but does not redirect.
- No dedicated mobile admin screen was found.
- No standalone room/dormitory browser screen was found, although room endpoints exist in the API client.
- No standalone visits/visitor-management screen was found.
- Support ticket client methods exist in `apiService`, but no current route clearly exposes a ticket screen separate from Lily Assistant support chat.
- Payment history depends on `/billing/history/paid`; if the endpoint is absent or returns 404, the screen cannot show paid history.
- Contract end display depends on `/dashboard/me` or related billing/profile payloads. Needs backend response verification.
